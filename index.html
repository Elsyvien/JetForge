03 Technical dossier

Built for systems, not isolated files.

Workspace context turns JET from a wall of mixed syntax into something the editor can explain.

A.01

Workspace model

See the generation graph.

Index templates, include fragments, skeletons, unresolved references, and output targets; inspect direct and transitive impact before changing them.

  • Explorer views
  • Impact reports
  • Current-buffer aware
A.02

Range mapping

Move both ways.

Reveal source from local preview—or preview from source—where the generated ranges can be mapped deterministically.

  • Source → preview
  • Preview → source
A.03

Fail-closed edits

Refactor without guessing.

Extract includes and rename or move referenced files through workspace edits that stop when the result cannot be established safely.

  • Extract include
  • Rename & move
A.04

Java help

Keep editor context inside JET.

Forward completion, hover, and definition through mappable template-Java regions when compatible Java tooling is installed. Local helper references, rename, and signatures stay conservative.

  • Tooling-aware
  • Conservative fallback
A.05

External compiler

Use the real toolchain.

Run a user-configured compiler and map parseable errors into the template editor. External execution remains blocked in Restricted Mode.

  • User configured
  • Trust respecting
A.06

Hardware workflows

Opt into IP-XACT.

Preview, generate, diff, validate, complete, and index IP-XACT output through an optional feature set that is disabled by default.

  • Optional
  • Off by default

04 Output-aware editing

One template language. Six destinations.

Choose a mode or let JetForge infer one from the file. When a name is ambiguous, explicit selection keeps the outer language honest.

  1. 01Java.javajet

    Classes, packages, and generated members

  2. 02HTML.htmljet

    Markup with embedded JET control flow

  3. 03XML.xmljet

    Structured documents and schemas

  4. 04C.cjet

    Headers, declarations, and native output

  5. 05Python.pythonjet

    Scripts and generated modules

  6. 06LaTeX.latexjet

    Typeset documents and technical output

Automatic detection is heuristic. Set the output mode explicitly when the filename does not make the destination clear.
