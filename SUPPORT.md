# JetForge Support

Use [GitHub Issues](https://github.com/Elsyvien/JetForge/issues) for reproducible bugs, compatibility requests, and feature proposals.

Before filing an issue:

1. Confirm the installed extension is the latest Marketplace version.
2. Run **JetForge: Open Getting Started** and verify the relevant prerequisite or compiler setting.
3. Reproduce with a sanitized template when possible.
4. Check the **TxtJet** output channel for a useful error message.

Include the JetForge version, VS Code version, operating system, template suffix, selected output mode, and the smallest sanitized reproduction. Remove proprietary paths, template contents, compiler output, and credentials before sharing logs.

Security-sensitive reports should follow [SECURITY.md](SECURITY.md), not a public issue.
